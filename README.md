# Salesforce CRUD Web Application

A full-stack web application that allows users to perform **Create, Read, Update, and Delete (CRUD)** operations on Salesforce standard objects without using the native Salesforce interface.

The application supports:

- Account
- Contact
- Lead
- Opportunity
- Case

Authentication is implemented using **OAuth 2.0** through a Salesforce External Client App.

---

## Features

### Salesforce Authentication

- Login with Salesforce
- OAuth 2.0 Authorization Code Flow
- Salesforce access token authentication
- Secure backend communication with Salesforce REST API
